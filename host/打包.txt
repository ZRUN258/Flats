导出虚拟环境的列表
conda env list
退出虚拟环境
conda deactivate
导出当前环境的包
conda list
启动/切换至名为name的Python环境
conda activate name
下载包
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 

启动软件Anaconda Prompt (miniconda)

切换至目标文件夹路径位置
cd C:\Users\DELL\Desktop\data\3DP_V2
cd C:\Users\DELL\Desktop\data\double_channel
启动虚拟环境
conda activate env_1
生成 spec 文件（我的 Pyinstaller 已经安装好了）
pyi-makespec -F -w call_main_window1.py
pyi-makespec -F -w double_channel_main.py
pyi-makespec -F -w double_channel_main_switch.py
