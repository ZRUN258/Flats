# Flats Web 上位机

这是无需安装依赖的静态网页上位机，使用浏览器 Web Serial API 连接 Arduino Mega 和可选的外部传感器。

## 启动

Web Serial 只能在安全上下文中运行。不要直接双击 `index.html`，请在 `host/web` 目录启动本地服务：

```bash
python3 -m http.server 8080
```

然后使用最新版 Chrome 或 Edge 打开 `http://localhost:8080`。Safari 和 Firefox 当前不支持 Web Serial。

## 路线 CSV

每行依次为方位角（度）、倾斜角（度）、半径（mm），不需要表头：

```csv
0,0,10
-45,15,10
45,15,10
```

也可以直接在页面生成按纬环分布的球冠覆盖路线。路线的最大倾角会根据“曲率半径”和“有效口径”自动计算，
因此既可显示完整半球，也可显示隐形眼镜一类浅球冠样品。有效口径不能大于曲率直径，超出时页面会按最大可用直径显示。

检测视图采用侧视三维投影。拖动模型下方的旋转滑块可以观察不同方位的扫描点和检测结果；曲率半径、
有效口径、球冠高度与最大倾角会实时联动。

## 采集模式

- **外部传感器串口**：保持原上位机的双串口方案。运动到位后，下一行包含的第一个数值作为读数；
- **运动控制器 MEASURE**：向运动板发送 `MEASURE`，接收 `DATA,value`；
- **手动录入/模拟**：适合无硬件时验证完整扫描流程。

扫描数据只保存在当前浏览器内存中。完成后使用“导出数据”保存 CSV，或“生成报告”调用浏览器打印为 PDF。
