# FLATS 品牌资产

标志由三个语义元素组成：球冠网格表示被测曲面，斜向轨迹表示探头扫描，蓝色靶点表示精密采样。

## 文件用途

- `flats-symbol.svg`：软件图标、头像、设备面板主标志；
- `flats-symbol-mono.svg`：丝印、激光雕刻、单色文档；
- `flats-logo-horizontal.svg`：产品铭牌、网站、文档封面；
- `flats-ppt-badge.svg`：PPT 页眉、封面角标和深色徽章；
- `png/`：常用尺寸透明 PNG；
- `icon.icns`：macOS 应用图标；
- `icon.ico`：Windows 应用图标。

## 颜色

- 精密黑：`#111318`
- 扫描蓝：`#0A7CFF`
- 光谱青：`#38D7D0`
- 辅助灰：`#59616E`

## 使用规范

- 标志四周至少保留图标宽度 12% 的净空；
- 小于 32 px 时优先使用 `flats-symbol.svg`，不要使用横版 Logo；
- 单色制造工艺只使用 `flats-symbol-mono.svg`；
- 不改变长宽比，不旋转，不替换渐变或在复杂图片上直接叠放；
- 横版 Logo 建议最小宽度为 180 px，PPT 徽章建议宽度为 240–360 px。
